# 1️⃣ Project Overview

## 1.1 Purpose

To design and develop a modern, scalable, production-ready mobile application for InsightBooks Africa using:

* **Stitch MCP** (UI generation & structured component scaffolding)
* **Dart/Flutter MCP** (App logic & architecture implementation)

The application will replicate the structure of the existing project while delivering a premium mobile experience inspired by the Crypto Trading Mobile App design from Dribbble.

---

# 2️⃣ Design & UX Specification

## 2.1 Design Inspiration

Inspired by:

* Crypto Trading Mobile App

## 2.2 Design Principles

* Clean, modern fintech aesthetic
* Card-based layouts
* Soft shadows & rounded corners (12–20px radius)
* Subtle gradients
* Micro-interactions & animations
* Elevated UI hierarchy
* Consistent spacing (8pt grid system)

## 2.3 Branding

* Colors must strictly follow project logo palette
* Centralized theme configuration:

  * Primary color
  * Secondary color
  * Accent color
  * Success, Warning, Error states
* Dark/light mode support (optional if brand allows)
