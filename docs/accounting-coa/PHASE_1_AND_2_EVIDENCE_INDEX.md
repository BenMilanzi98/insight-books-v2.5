## Phase 2 contracts Phase 3 must respect

- `AccountMappingService.resolveMappedAccount(context, mappingKey, db)` — same signature, registry
  backing, explicit typed errors (`MissingAccountMappingError`, `InactiveAccountError`,
  `NonPostingAccountError`).
- `AccountingContext` (business-scoped, session-derived) for every command.
- `recordAccountingAudit` append-only audit writes.
- `AcctV2FeatureFlag` server-controlled flags; scope precedence unchanged.
- Additive-only migrations; no FK cascade from tenant onto new governance tables.
- Boundary rules: domain purity, no UI → infrastructure imports, no name matching in new code.
