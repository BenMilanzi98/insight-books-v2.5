# Mapping Status Model

Statuses in `MAPPING_STATUS`: UNMAPPED → SUGGESTED → MATCHED → PENDING_VERIFICATION → VERIFIED → PENDING_APPROVAL → ACTIVE, plus CONFLICT, STALE, INACTIVE, SUPERSEDED, BLOCKED, MANUAL_REVIEW.

SUGGESTED / MATCHED / VERIFIED are never automatically ACTIVE.
