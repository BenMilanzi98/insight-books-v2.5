6.4. Submitting Offline Transactions

 
Once the POS system regains connectivity to the MRA server, it must upload all locally stored offline transactions to the MRA server.
The POS sends these transactions, including the offlineSignature, to indicate they were made offline.
Transactions must be submitted within the allowed transaction age to ensure compliance.
 
On the other end, the MRA server processes these transactions and validates them using the included offlineSignature. This validation is done with the secret key that was provided to you during terminal activation and is also held by the MRA.
