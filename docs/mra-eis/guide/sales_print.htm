5.3. Sales

 
 
The sales module is responsible for submitting real time terminal sales transaction to the authority. It encompassed three endpoints which are
 
  • Submit Sales Transactions
     
      This is responsible for submitting real time terminal sales transactions to MRA
     
  • Last Submitted Online Transaction
     
        This endpoint retrieves the details of the last invoice submitted when the terminal was online. It serves to verify whether an invoice was successfully received by the authority, particularly in cases of  transmission interruptions such as power failures or application crashes.
     
  • Last Submitted Offline Transaction
     
          This endpoint handles the retrieval of information regarding the last transaction submitted while the terminal was offline
