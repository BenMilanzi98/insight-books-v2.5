# UI/UX Gap Register

| Gap | Current | Target |
|-----|---------|--------|
| Sidebar labels | Variance / Expense budgets / Revenue forecasts | Reports / Budgets / Forecasts (clear ownership) |
| Dashboard | Thin list pages | Executive cards + charts from live data |
| Planner | Basic matrix | Sticky columns, quarters, bulk actions, mobile cards |
| Wizard | Flat create form | 6-step guided creation |
| Completion score | None | Explainable % with drill-down |
| Status badges | draft/active | Full lifecycle + approval |
| Reports centre | Single P&L vs actual | Full catalogue + drill-down + export |
| Empty / error states | Minimal | Explicit, no fake sample data |
| Financial Planning page | Parallel pilot | Redirect into BF |
