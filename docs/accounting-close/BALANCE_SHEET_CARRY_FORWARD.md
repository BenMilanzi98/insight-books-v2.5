# Balance Sheet Carry-Forward

## Default: continuous General Ledger

Assets, Liabilities, and permanent Equity retain cumulative balances across years.

- Next-year opening **reporting** balances = prior year post-closing permanent balances from JE lines.
- **No** opening journal is created for Bank, AR, Inventory, FA, AP, Loans, Taxes, Capital, RE, Reserves.
- Temporary accounts begin the new year at zero because Closing Journals zeroed them.

## Separate-ledger carry-forward

Only if explicitly configured later via Opening Balance framework. Not default.
