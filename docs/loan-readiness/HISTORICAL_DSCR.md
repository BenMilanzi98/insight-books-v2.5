# DSCR Formulas

Version: `DSCR_CFADS_OVER_DEBT_SERVICE_V1`

```
DSCR = CFADS ÷ Total Debt Service
```

CFADS (default): EBITDA − cash tax (configurable by lender profile later).  
Debt Service: existing + proposed principal + interest (+ fees).

Interest Coverage: `ICR_EBITDA_OVER_INTEREST_V1` = EBITDA ÷ Interest.
