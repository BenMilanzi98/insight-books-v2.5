# Debt Capacity Engine

Formula version: `DEBT_CAPACITY_CFADS_TARGET_DSCR_V1`

```
Max Affordable Debt Service = CFADS ÷ Target DSCR
Available for Proposed = Max − Existing Debt Service − Min Cash Retention
Indicative Principal = annuity inversion of binding (minimum) available payment
```

Label: *Indicative internal debt-capacity estimate — not a lender approval or offer.*

Revenue-only calculation is rejected (`LRD-017`).
