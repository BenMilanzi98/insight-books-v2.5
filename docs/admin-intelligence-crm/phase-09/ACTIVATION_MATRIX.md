# Activation Matrix

| Activation type | Criteria (planned) | Live today |
|-----------------|--------------------|------------|
| User activation | Invite/accept + first meaningful action (not login alone) | NOT_INSTRUMENTED |
| Customer product activation | Config (if required) + ≥1 user value + first value on core feature | NOT_INSTRUMENTED |
| Module activation | Module-specific first value | NOT_INSTRUMENTED |
| Feature activation | Feature first value (+ config if required) | NOT_INSTRUMENTED |
| MRA EIS activation | Entitlement active + config + first accepted fiscal | NOT_INSTRUMENTED (candidates exist) |
| Android activation | First Android meaningful action | NOT_INSTRUMENTED |

Tenant created / subscription started / login alone → **never** product activation.
