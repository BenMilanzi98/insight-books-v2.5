# Support Reconciliation Audit

| Pair | Status | Notes |
|------|--------|-------|
| Ticket count vs status history | NOT_FOUND | Wave 3–4 |
| Message count vs activities | NOT_FOUND | Wave 2+ |
| SLA clocks vs breach KPIs | NOT_FOUND | Wave 3+ |
| CsCase count vs Support count | N/A | Must never be equated |

**Anti-pattern:** Recon that “imports” CS cases or contact emails as tickets.
