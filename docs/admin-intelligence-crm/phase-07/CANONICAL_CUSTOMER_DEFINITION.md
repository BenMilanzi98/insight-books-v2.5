# Canonical Customer Definition

| Term | Meaning in InsightBooks platform control plane |
|------|--------------------------------------------------|
| **Customer** | The commercial/service relationship represented by a **Tenant** |
| **Tenant** | Top-level isolated platform account (`Tenant.id`) |
| **Branch** | Location/unit under Tenant |
| **User** | Person with access to the Tenant |
| **Billing account** | Same as Tenant unless a future distinct billing entity is introduced |
| **Portfolio** | Governed group of Tenants assigned to a CS/account owner |

Do not treat Branch or User as a separate Customer.  
Do not use Tenant customer AR (tenant's end-customers) as InsightBooks Customer.
