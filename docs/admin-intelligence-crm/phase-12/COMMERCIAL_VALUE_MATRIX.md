| Invoice / Payment totals | Billing | Not Opportunity value | WRONG_DOMAIN |
| Expected revenue invent | — | Honesty flags forbid | FORBIDDEN |
| Empty Pipeline “0 value” | Reports | NOT_INSTRUMENTED / honesty | FORBIDDEN false zero |

**Rule:** Opportunity value ≠ contracted/billed/recognised Revenue.
