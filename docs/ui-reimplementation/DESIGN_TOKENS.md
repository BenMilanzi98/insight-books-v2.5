# Design Tokens

Semantic CSS custom properties live in `app/globals.css` `:root`.

Key groups: brand (`--primary-*`), surfaces (`--surface-*`, `--background-*`), text (`--text-*`), borders, actions, status, focus, shadows, spacing (`--space-*`), radius, motion, z-index (`--z-*`).

Legacy aliases `--primary-color`, `--dark-bg*` retained for existing sidebar CSS.
