# Z-Index System

| Token | Value | Use |
|-------|------:|-----|
| `--z-base` | 0 | Content |
| `--z-sticky` | 100 | Sticky headers |
| `--z-dropdown` | 200 | Menus |
| `--z-popover` | 300 | Popovers |
| `--z-drawer` | 400 | Sidebar / drawers |
| `--z-backdrop` | 450 | Overlays |
| `--z-modal` | 500 | Modals |
| `--z-toast` | 600 | Toasts |
| `--z-critical` | 700 | System alerts |
